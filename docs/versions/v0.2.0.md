# v0.2.0(2026-09-06)

## Changed

- HTTP 入口(axum)强制 HTTPS:复用 TCP 通道的 rustls 配置(TLS 1.3),不再存在明文 HTTP 监听路径;响应统一携带 HSTS 头。
- 新增可选的 HTTP→HTTPS 自动跳转:配置 `SERVER_HTTP_REDIRECT_ADDR`(如 `0.0.0.0:80`,不写死端口)即启用 308 跳转监听;未配置则进程内无任何明文监听(PRD 红线 R1)。
- 第三方依赖统一收敛到根 `Cargo.toml` 的 `[workspace.dependencies]` 管理:`=` 锁定版本 + 分组注释,子 crate 一律以 `workspace = true` 引用。

## Added

- criterion 性能基准套件覆盖框架全部热路径,全部可离线运行:net-kit 帧编解码与 TCP/TLS 连接管线(往返延迟/握手/吞吐)、protocol 消息编解码与路由分发、gateway HTTP 链路(axum + Bearer 鉴权 + argon2)与 TCP 房间端到端(建连绑定/心跳/聊天广播,loopback 真实 TLS + 内存基础设施)。参考数值见 README"性能基准"一节,规范见 AGENTS.md 第 10.9 节。
- 依赖 `axum-server 0.8`(gateway,`tls-rustls-no-provider`,提供者仍为 ring)与 `criterion 0.5.1`(bench 专用)。

## Fixed

- TCP 连接断开后 `handle_connection` 在 `writer.await` 处永久挂起:连接上下文仍持有发送队列克隆,写 task 等不到队列关闭,连接处理器不返回,导致 `max_connections` 并发名额随每次断开持续泄漏、达到上限后拒绝一切新连接。修复为清理阶段先整体丢弃连接上下文再等待写 task 退出,并新增端到端回归测试(`connection_permits_are_released_after_disconnect`)。
